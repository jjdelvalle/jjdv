{%- comment -%} schema.org Person node, homepage only -- one canonical entity per site. This is what lets Google merge this site with the LinkedIn/GitHub profiles it already trusts, instead of treating them as unrelated pages that happen to share a name. The sameAs array does the actual work. Every optional field is guarded and emitted with a LEADING comma, so the JSON stays valid no matter which config keys are set.
